# cchecker

Checks C code for the rules a project relies on, and runs the usual analyzers in one command. It is written in
[Agentica](https://github.com/agentica-lang/agentica) and reads clang's JSON AST.

This is a work in progress. The plan and the phases are in [issue 1](https://github.com/agentica-lang/cchecker/issues/1).
